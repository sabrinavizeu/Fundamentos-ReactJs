## 📖 Sobre

Cada arquivo deste repositório é um exemplo isolado, cobrindo um conceito
específico de React — da base (JSX, componentes) até tópicos mais avançados
(Context API, efeitos colaterais). São arquivos HTML únicos, sem processo de
build: carregam **React**, **Babel** (pra entender JSX direto no navegador) e
**Tailwind CSS** via CDN, então cada um roda sozinho, bastando abrir no
navegador.

## 🛠️ Tecnologias

- React 18 (via CDN)
- Babel Standalone (JSX direto no navegador)
- Tailwind CSS (via CDN)

## ▶️ Como rodar

Não precisa instalar nada — é só abrir qualquer um dos arquivos `.html`
direto no navegador, ou acessar a versão publicada de cada um pelo link na
tabela acima (depois de ativar o GitHub Pages neste repositório).
